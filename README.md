# SPUMP Token Metadata Repository

This repository contains the **official metadata assets** for a SCOTTY PUMPKIN utility token**, including token information, branding resources, and references used by wallets, explorers, and on-chain applications.

It serves as the **single source of truth** for token identity and presentation.

---

## Purpose

The goal of this repository is to provide:

- Standardized token metadata
- Publicly verifiable branding assets
- Consistent references for ecosystem integrations
- Transparent updates to token identity over time

This repository does **not** contain private keys, mint authority credentials, or sensitive information.
